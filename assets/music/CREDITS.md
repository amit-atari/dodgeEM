## Track details

- **Level 1 / Level 3**: Juhani Junkala. Chiptune, seamless loops (the source page says "5 tracks, all seamlessly looping!"). Original files: `level1.mp3` (~80 s) and `level3.mp3` (~91 s), 160 kbps.
- **electro**: Pro Sensory. Synthwave/electro (the page says "all my music is public domain"). Original file: `synth_wave_sept_7_5_44_mastered.mp3`, ~139 s, 192 kbps.
- **Neon Hyperdrive**: Adiutorium. "A fast paced futuristic music". Original file: `neon_hyperdrive.mp3`, ~130 s, 320 kbps.
- **Slipstream**: cinameng. Synth wave. Original file: `slipstream.mp3`, ~64 s, 320 kbps.
- **Calm Relax 1 (Synthwave 421k)**: The Cynic Project, written for the game Pixelsphere. Relaxing pads. The file is the shorter `lifewave.mp3` version attached to the same page (~153 s, 160 kbps). The full 19 MB version (`007_Synthwave_421k.mp3`) was too large.
